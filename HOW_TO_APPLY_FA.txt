راهنمای نسخه Xray برای LEVIKO VPN

این ZIP نسخه کامل سورس پروژه است. آن را به‌صورت کامل در مخزن GitHub جایگزین کنید (به‌خصوص فایل‌های تکی را جداگانه کپی نکنید).

پس از Commit روی شاخه main، وارد Actions شوید و workflow با نام Build LEVIKO VPN APK را اجرا کنید.

در این نسخه، GitHub Actions ابتدا کتابخانه بومی Xray یعنی libxray.aar را از سورس رسمی XTLS/libXray می‌سازد، سپس APK را کامپایل می‌کند. نیازی به آپلود دستی AAR نیست.

فایل libxray.aar عمداً داخل ZIP نیست و در هر بار Build در محیط GitHub ساخته می‌شود.

توجه: ساخت موفق در GitHub Actions و آزمایش اتصال واقعی روی گوشی دو مرحله جدا هستند. تا قبل از سبز شدن Build و آزمایش کانفیگ‌های واقعی، نسخه را کاملاً تأییدشده تلقی نکنید.
