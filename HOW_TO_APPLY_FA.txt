راهنمای ساخت LEVIKO VPN با Xray

این ZIP را کامل در مخزن GitHub جایگزین کنید و مطمئن شوید فایل فعال دقیقاً در مسیر زیر قرار دارد:
.github/workflows/build-apk.yml

فایل build-apk.yml در ریشه پروژه، Workflow فعال GitHub Actions نیست؛ نسخه تکراری آن حذف شده تا اشتباه نشود.

Workflow ابتدا وابستگی‌ها و Android NDK را نصب می‌کند، سپس اسکریپت رسمی v2ray_box را دریافت می‌کند. چون اسکریپت فعلی v2ray_box به API قدیمی nodep.CallResponse متکی است، بخش تست پینگ قدیمی آن برای سازگاری با libXray فعلی به‌صورت بی‌اثر نگه داشته شده است. LEVIKO پینگ سرورها را با TCP خودش محاسبه می‌کند.

سپس libxray.aar ساخته و بررسی می‌شود و در صورت موفقیت APK ساخته و به‌عنوان Artifact و GitHub Release منتشر می‌شود.

نکته: فایل AAR داخل ZIP نیست؛ در هر بار اجرای GitHub Actions ساخته می‌شود. ساخت موفق در CI و تست اتصال واقعی روی گوشی دو مرحله جدا هستند.
